Download for Android

Android phones only. The file is a few tens of MB, so use WiFi if you can.

How to install

  1. Tap Download for Android and wait for the file to finish downloading.
  2. Open the downloaded EduPortal .apk file. If Android asks, allow "Install unknown apps" for your browser or file manager.
  3. If Google Play Protect says "Unsafe app blocked", tap "Install anyway". This warning appears because the app is not on the Play Store yet.
  4. Open EduPortal and log in with your website account, or sign up in the app.

What you get

  • Chapter-wise notes and subjective questions as PDFs
  • Previous year papers
  • Mock tests with time analysis, a result report and review
  • Daily goal and study streak
  • AI doubt solver and direct messages
  • Updates arrive inside the app
